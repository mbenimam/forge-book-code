# forge-book-code

Starter code for **Forge: build your own game engine, one game a week**.

You write the engine yourself, game by game. This repository holds the starting point for every
chapter, so you can work along with the book.

Chapters appear here as the book is written. Each chapter has two tags:

- `chNN-start`: the project as it looks when the chapter begins. Check this out and work along.
- `chNN-solution`: the project as it looks when the chapter ends, to compare with your own.

Nothing here is ready yet. The first chapter will appear soon.
